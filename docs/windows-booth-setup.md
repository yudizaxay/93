# Windows Booth Configuration

- Power settings: Sleep OFF, Display sleep OFF, Screen saver OFF.
- Notifications OFF, Focus Assist ON.
- Set the app to auto-launch on login (Task Scheduler entry or Startup
  folder shortcut to the installed `.exe`), so the flow is:
  Power On -> Windows starts -> auto-login -> game launches fullscreen ->
  ready. No staff should need to open a terminal or browser.
- Fix the TV's resolution and confirm Windows display scaling renders
  the kiosk UI correctly at that fixed resolution before the event.
- Pre-set system volume to the desired booth level.
- Do not disable Windows Update entirely or otherwise weaken security
  settings beyond what's listed here.
